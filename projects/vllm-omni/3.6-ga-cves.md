## Method notes

- The immutable digest above is a multi-architecture image index. Dispatching
  Clair directly against that index returned `status: unsupported` in run
  `45428587289`; dispatching the release tag with `platform=linux/amd64`
  correctly resolved and scanned the child manifest.
- Advisory aliases were normalized through OSV so duplicate GHSA/PYSEC records
  appear once under their canonical CVE ID.
- Trivy vuln-mode cross-check was dispatched as run
  [`45428589859`](https://github.com/neuralmagic/nm-cicd/actions/runs/45428589859)
  and was still scanning the large image when this release-notes list was
  generated. Clair remains the release sign-off source.
